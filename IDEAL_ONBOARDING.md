# Deel Connector — Ideal Onboarding

## Setup Steps
1. Log in to the Deel Organization portal at `app.letsdeel.com`.
2. Go to **Organization Settings > Integrations > API Tokens**.
3. Generate a dedicated API Bearer Token with Organization and Payroll scopes.
4. Open the Imperal Deel Connector panel and enter the API Bearer Token.
5. Submit connection — the connector tests authentication against `/rest/v2/people?limit=1`.
